# Course Recommendation 用户指南

本文档介绍如何通过对话使用 Course Recommendation 功能获取课程推荐、课程详情和课程对比结果。

---

## 1. 功能概览

Course Recommendation 面向选课辅助场景。用户可以用自然语言描述兴趣、专业背景、年级、已修课程和偏好，Agent 会基于本地打包的课程目录给出推荐或对比结果。

| 功能 | 说明 |
|------|------|
| 浏览课程目录 | 查看当前可用于推荐的课程列表 |
| 个性化推荐 | 根据兴趣、专业、已修课程、语言偏好、时间偏好和记忆内容推荐课程 |
| 查看课程详情 | 查询单门课程的完整信息 |
| 对比课程 | 对比多门课程的学分、难度、工作量、评分和先修要求 |
| 可视化展示 | 在右侧工作区显示课程卡片 |

---

## 2. 使用方式

### 2.1 获取课程推荐

直接告诉 Agent 你的兴趣、专业背景和已修课程：

```text
帮我推荐几门适合大三计算机专业、对 AI 感兴趣的课程。
```

```text
我已经修过 CS109，想学 machine learning，有什么课推荐？
```

Agent 会调用 `recommend_courses` 工具生成排序后的推荐列表，并在需要时调用 `show_courses` 将结果展示到课程卡片 Widget。个性化推荐时，Agent 可以先读取 Agent Memory 中与课程偏好、学习计划或个人背景有关的记忆，再把相关内容传入推荐工具。

### 2.2 浏览课程目录

可以按院系或课程层级查看课程：

```text
有哪些 Computer Science 的课程？
```

也可以按教师、课程类型、授课语言、学分范围等条件继续缩小结果。

### 2.3 查看课程详情

可以查询某门课的完整信息：

```text
查看 CS405 的课程详情。
```

返回内容通常包括课程名称、课程代码、班级 ID、院系、学分、总学时、教师、上课时间、课程类型、授课语言和名额信息。

### 2.4 对比课程

可以让 Agent 对比多门课程：

```text
帮我比较 CS405 和 CS310。
```

对比结果会展示课程的学分、总学时、教师、上课时间、课程类型、授课语言和名额，方便用户判断哪门课更适合当前计划。

---

## 3. 推荐依据

当前推荐逻辑基于本地课程目录，主要考虑以下因素：

- 用户兴趣是否匹配课程名称、院系、教师、课程类型、授课语言或上课时间
- 用户专业是否匹配课程院系或推荐人群
- 已完成课程是否应从推荐结果中排除
- 用户偏好的授课语言是否匹配
- 用户希望避免的上课时间是否冲突
- 课程学分、总学时和本科生名额等基础信息

推荐结果会返回 `memory_used` 和每门课的 reasons，方便用户看到推荐是否使用了记忆内容，以及每门课为什么被推荐。

---

## 4. 常见问题

### Q: Course Recommendation 使用真实教务数据吗？

当前版本使用从本地课程 CSV 转换得到的打包课程目录，运行时不依赖 `tmp/` 临时目录。后续可以继续接入实时教务系统数据。

### Q: 推荐结果会自动帮我选课吗？

不会。Course Recommendation 只提供选课建议和课程信息展示，不会执行选课、退课或提交操作。

### Q: 为什么某门课程分数较低？

可能是兴趣关键词、专业、授课语言、时间偏好或已修课程匹配度较低。如果课程已经出现在已修课程中，推荐工具会避免继续推荐该课程。
