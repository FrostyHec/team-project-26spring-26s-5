# Policy Search 用户指南

本文档介绍如何使用校园政策搜索功能查询南科大官方政策、培养方案和规章制度。

---

## 1. 功能概览

Policy Search 基于 RAG（检索增强生成）架构，将南科大教务处的官方 PDF 文档向量化后存入本地 FAISS 索引。用户提出问题时，系统先从索引中检索相关政策片段，再由 LLM 基于检索结果生成回答，确保回答有据可查。

| 能力 | 说明 |
|------|------|
| 政策检索 | 从 21 份官方 PDF 中检索相关条款 |
| 来源引用 | 回答附带 `[来源 n]` 标注，可追溯到具体文档和页码 |
| PDF 查看 | 前端支持在线查看源 PDF 并跳转到对应页 |

## 3. 使用方法

### 3.1 前端使用

1. 在技能选择面板中选择 **Policy Search**
2. 在对话框输入问题
3. 系统自动检索相关政策并生成回答
4. 回答中的 `[来源 n]` 可对应到具体文档和页码

### 3.2 API 调用

```http
POST /chat/stream
Content-Type: application/json

{
  "session_id": "<session-id>",
  "message": "转专业需要什么条件？",
  "skill": "policy_search"
}
```

## 5. 添加新的政策文件

1. 将 PDF 文件放入 `pdfs/` 目录
2. 如果是扫描件（图片型 PDF），先用 OCR 添加文字层：
   ```bash
   ocrmypdf -l chi_sim --skip-text --optimize 0 pdfs/新文件.pdf pdfs/新文件_ocr.pdf
   ```
3. 重建索引：
   ```bash
   uv run agent-cli build-policy-index --env-file .env
   ```
4. 重启后端服务

> 当前索引已预构建并包含在仓库中（`output/policy_index/`），无需配置 Embedding API Key 即可直接使用。只有添加新 PDF 后重建索引时才需要 `EMBEDDING_API_KEY`。
